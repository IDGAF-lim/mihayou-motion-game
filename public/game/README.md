# 游戏与原 App 集成

使用项目根目录的服务打开 `/game/`。推荐手机端为 `apps/MihaSensor-integrated.apk` 增强版，连接 `ws://电脑IP:端口/sensor`，经服务转发到浏览器 `/ws`。原始 v0.4.9 APK 同样兼容。

- `game.js`：组员规则核心、谱面验证、难度窗口、固定偏移、迟到截止、碰撞与通关。
- `app.js`：音频、页面、校准、双人流程和成绩导出。
- `match.js`：从原卡点生成难度配置，双人有效局推进及成绩比较。
- `calibration.js`：节拍匹配、中位数、异常过滤和质量检查。
- `demo-chart.js`：原 30.004 秒、17 障碍谱面；原 JSON 和 TXT 保留。
- `public/game-link.js`：服务事件、时钟映射和原 App 兼容。

简单档在原谱面中选取相隔至少 2.3 秒的障碍，窗口 ±220ms；普通原 17 个障碍、±150ms；困难同样 17 个卡点、±100ms、画面较快。没有新增伪卡点。

```text
判定时间 = 映射到音乐轴的动作时间 - 开局偏移
通过条件 = 正确方向且绝对误差不超过本难度窗口
```

增强版完成手机时钟同步后，使用估算源动作时刻映射到浏览器和音频输出；原版没有同步，退回电脑收件时刻映射。偏移仅扣一次，准备阶段可调，局内固定。保护期最多 250ms，不扩大动作判定窗口，死亡后不复活。

双人同一手机依次玩。第一位结束后显式换手，第二位点击开始。难度和偏移锁定；一组内外部修改配置不改变第二位的比赛参数。有效结束才记成绩；中断重试当前人。通关优先，其次通过障碍数、存活时间；双通关平局。

试听中滑条立即更新补偿后偏差；八拍校准要求至少 6 个稳定样本。页面隐藏、通信断开和切换通信测试局时停止校准，隐藏时游戏暂停。原 APK 断网不能保证立即发现。

`Mihayou.getState()`、`subscribe(fn)`、`start()`、`ready()`、`setCalibration(ms)`、`receiveAction(event)` 保留。公开接入接口仍由同一适配器调用，不能再额外建立第二套手机收件逻辑。

测试方法和真实手机边界参见根目录 README、`验证记录.md`。
