# 咪哈友 · 蓝牙传感器终端版

2026-11-17，0.6.1-ble。手机仅采集原始加速度与姿态，通过 BLE 通知直接传到电脑浏览器；握姿校准、重力消除、动作识别和游戏判定在电脑完成。本工程是在原 APK 静态信息重建工程上修改的开发版，独立包名与开发签名，原版原样保留。

## 开始试玩

1. 解压 Windows 完整包，双击 `01-启动游戏.cmd`，用 Chrome 或 Edge 打开电脑本机地址。蓝牙链路不要求手机与电脑在同一 Wi-Fi。
2. 手机安装 `apps/MihaSensor-integrated.apk`，名称“咪哈友·蓝牙终端”，版本 `0.6.1-ble`。若旧增强版签名不同导致安装失败，需先卸载旧增强版；原版 `com.mihayou.sensor` 可并存。
3. 手机开启蓝牙，App 点“启动蓝牙”，允许附近设备权限并保持前台；电脑开启蓝牙，游戏页点“连接手机蓝牙”。选择器可能显示手机名称或设备地址。
4. 电脑点“校准动作”，保持握姿静止约 1 秒，按状态提示上挥一次，再静稳至“已就绪”。更换握姿或玩家后重新校准。
5. 每次识别后电脑执行至少 550 ms 冷却，再等待连续 120 ms 低活动信号接受下一次动作；持续采样，无需检测反向回正。参数是待真机调节的起点。采样间断会取消待确认动作；断开或加速度断流 1 秒会中断对局，重连必须重新校准。
6. 电脑选简单难度，试听节拍并实时拖偏移，或做八拍自动校准，再开始游戏。
7. 双人选轮流模式，第一位有效结束后点换手；第二位重新示教后再开始。比赛中两人的难度、偏移相同。
8. 先导出需要的记录，再双击 `03-关闭服务.cmd`。关闭网页不会停止服务。

源码包无捆绑运行程序，需安装 Node.js 后 `npm start`。服务默认端口 8765，被占用时顺延，以页面地址为准。游戏在 `/game/`，测试台在 `/`。

## 游戏规则

电脑键盘可直接试玩，不需要连接手机。点击开始后，↑ 跳跃，↓ 下蹲，空格也可跳跃；按住不重复触发。主界面的箭头按钮支持点击。暂停时不接收动作，继续后恢复游戏焦点；编辑姓名、偏移或选择难度时，方向键保持控件自身的行为。

Funny Pigs 约 30.004 秒；地面和头顶两种障碍，上挥跳、下挥蹲。通过或碰撞结束，没有 Perfect/Good。保留组员提供的游戏核心、音乐及卡点。

| 难度 | 谱面 | 判定窗口 | 速度 |
| --- | --- | --- | --- |
| 简单 | 原谱面抽取 9 个障碍，至少间隔 2.3 秒 | ±220 ms | 慢 |
| 普通 | 原 17 个障碍 | ±150 ms | 普通 |
| 困难 | 相同 17 个原卡点 | ±100 ms | 快 |

原谱面部分相邻动作不足一秒，需要真机验证舒适度，先用简单档。双人依次玩，通关优先，其次比较通过数和存活时间；同一障碍死亡或双通关平局。中断不记有效成绩。成绩可导出 JSON，刷新会清空页面成绩。

## 判定校准

偏移 −200 至 +400 ms、步长 5 ms，准备/试听时实时更新并保存到电脑及同步其他页面。正值把判定时刻前移，仅扣一次。正式局内固定偏移；双人一组固定相同设置。

八拍自动校准播放 8 声、每秒一拍，跟随上挥并自然收手。至少 6 拍稳定才采用中位数建议值，异常/超范围保留原值。先完成动作校准，再校准音乐偏移。固定偏移不能消除随机传输抖动。

服务端仍保留经典 Wi-Fi/WebSocket 协议供旧客户端和诊断工具兼容；选择蓝牙模式后忽略旧控制器输入及状态。BLE 每包 20 字节，带协议版本、传感器类型、递增序号、手机单调时间毫秒及三轴原始值。电脑按手机时间计算动作持续时间，按候选动作首包的电脑接收时刻映射音乐；相对积压检测不是单程延迟测量。Node 仍负责页面、通信局号和设置。主动断开后可显式选择“使用键盘”。

## 版本区别

- `apps/MihaSensor-integrated.apk`：本次 BLE 原始传感器终端，独立包名 `com.mihayou.sensor.integrated`。无 IP 输入、手机端识别或网络同步测速；断线后在电脑手动重连并重新校准。
- `apps/MihaSensor-debug-0.4.9.apk`：你给的原 APK 原样保留，SHA256 为 `ED3CB68E13550206D6EE666E02B337116B87304FE96C6012A9A164164718F659`。按静止握姿定义上下，不支持任意方向示教、手机同步测速或严格跨局标记。使用它时 RTT 为空正常。
- `apps/MihayouMotionController.apk` 和 `MihayouLinkTest.apk`：此前备用控制器和测试工具，本次无需安装。

原版与增强版可并存，同时只开一个发送动作。增强版不是原签名覆盖升级；重建和构建说明见 `android-sensor/README.md`。

## 验证与分发

`npm test` 检查服务、适配、规则、校准、双人、BLE 帧与电脑识别；`npm run test:browser` 需 Playwright/Chrome，含模拟 Web Bluetooth 原始数据整曲验收；`npm run test:sensor` 需 `JAVA_HOME` 和 `JSON_JAR`，验证 Java BLE 编码及保留的旧版通信。签名密钥、运行记录、用户设置和构建目录不分发。

已通过 APK 构建及签名校验、34 项 Node 与 10 项浏览器自动测试和 Java 编码/旧版兼容验证。未做实体 Android 安装、真实蓝牙传输、真实挥动误触率及课堂环境验收，不能把合成测试写成用户实测。详见 `验证记录.md`。
