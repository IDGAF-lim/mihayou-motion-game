# 咪哈友 · MihaSensor 增强整合版

2026-10-25。本项目将你提供的 MihaSensor APK 与组员的音乐避障游戏、电脑同步和测试台整合。增强 App 是基于原 APK 静态信息重建的开发版，保留界面结构和姿态补偿流程；没有原工程与签名，因此独立包名安装，与原版并存。原版原样保留。

## 开始试玩

1. 解压 Windows 完整包，双击 `01-启动游戏.cmd`；再双击 `02-连接测试台.cmd` 查看电脑 IP 和端口。
2. 手机安装 `apps/MihaSensor-integrated.apk`，名称“咪哈友·原版增强”。
3. 手机和电脑连接同一个 Wi-Fi 或热点，App 填测试台给出的 `ws://电脑IP:端口/sensor`，点“连接并测量”，等 RTT 出现。
4. 点“开始检测并示教”，静止约一秒；朝舒服方向挥一次作为上挥，末端停稳、反向回位、再次停稳，完成示教。反方向正式挥动就是下挥。
5. 每次正式动作都经过末端停稳、反向回位、原位停稳才重新就绪。回位和示教不发送游戏动作。阈值可以调整；只有确实回位时才用手动重新就绪。
6. 电脑选简单难度，试听节拍并实时拖偏移，或做八拍自动校准，再开始游戏。
7. 双人选轮流模式，第一位有效结束后点换手；第二位重新示教后再开始。比赛中两人的难度、偏移相同。
8. 先导出需要的记录，再双击 `03-关闭服务.cmd`。关闭网页不会停止服务。

源码包无捆绑运行程序，需安装 Node.js 后 `npm start`。服务默认端口 8765，被占用时顺延，以页面地址为准。游戏在 `/game/`，测试台在 `/`。

## 游戏规则

Funny Pigs 约 30.004 秒；地面和头顶两种障碍，上挥跳、下挥蹲。通过或碰撞结束，没有 Perfect/Good。保留组员提供的游戏核心、音乐及卡点。

| 难度 | 谱面 | 判定窗口 | 速度 |
| --- | --- | --- | --- |
| 简单 | 原谱面抽取 9 个障碍，至少间隔 2.3 秒 | ±220 ms | 慢 |
| 普通 | 原 17 个障碍 | ±150 ms | 普通 |
| 困难 | 相同 17 个原卡点 | ±100 ms | 快 |

原谱面部分相邻动作不足一秒，需要真机验证舒适度，先用简单档。双人依次玩，通关优先，其次比较通过数和存活时间；同一障碍死亡或双通关平局。中断不记有效成绩。成绩可导出 JSON，刷新会清空页面成绩。

## 判定校准

偏移 −200 至 +400 ms、步长 5 ms，准备/试听时实时更新并保存到电脑及同步其他页面。正值把判定时刻前移，仅扣一次。正式局内固定偏移；双人一组固定相同设置。

八拍自动校准播放 8 声、每秒一拍，跟随上挥并回位。至少 6 拍稳定才采用中位数建议值，异常/超范围保留原值。固定偏移不能消除随机网络抖动。

增强版每秒执行 HTTP 四时间戳同步，再用 WebSocket `/sensor` 发动作。测试台显示手机 RTT 中位数/P95、估算动作上行和原始记录。单程估算依赖近似对称链路，包含识别确认等待，不能当纯网络精密测量。

## 版本区别

- `apps/MihaSensor-integrated.apk`：本次增强版，独立包名 `com.mihayou.sensor.integrated`，支持方向示教、防复位重复触发、同步、测速、runId 和自动重连。
- `apps/MihaSensor-debug-0.4.9.apk`：你给的原 APK 原样保留，SHA256 为 `ED3CB68E13550206D6EE666E02B337116B87304FE96C6012A9A164164718F659`。按静止握姿定义上下，不支持任意方向示教、手机同步测速或严格跨局标记。使用它时 RTT 为空正常。
- `apps/MihayouMotionController.apk` 和 `MihayouLinkTest.apk`：此前备用控制器和测试工具，本次无需安装。

原版与增强版可并存，同时只开一个发送动作。增强版不是原签名覆盖升级；重建和构建说明见 `android-sensor/README.md`。
